# v9 — 移除站内的能力自我披露

## 起因
"We are not automated yet / High-throughput is a 2027 target, not a current capability"
属于内部表述，不应出现在官网上。

## 改动
- 平台页「What we are not」删掉该条（保留 not a model company / not a CRO），网格改 auto-fit
- 服务页自动化区块：
  - 标题 "Where we are, and when that changes." → "Three tiers of capacity."
  - 导语删除 "Today every project is run by a named scientist… lower throughput, better judgement"
  - 三档改为 Available now / Rolling out 2026–27 / From 2027，每档写客户得到什么
  - "Bench-scale, expert-led" 替代 "Expert-led, manual"
- 平台页第 04 层 bullet："Automation roadmap published, not implied" → "Capacity roadmap with committed windows"
- 设计语言 12.3 增加禁用项「自我披露能力缺口」+ 正反例对照表

## 原则
诚实 ≠ 自曝短板。描述提供什么，不描述缺什么；时间点可以写，但不能写成能力认罪书。
