02Lab automation

Where we are, and when that changes.

Today every project is run by a named scientist at the bench. That is a deliberate trade: lower throughput, better judgement. Automation is how we keep the judgement and remove the ceiling — on a timeline we are willing to publish.

Today
Expert-led, manual

Every project is run by a named scientist. Low throughput, high judgement — which is exactly what early programmes need.

  • Named application scientist per project
  • Bench-scale, 1–5 L
  • 7–10 day typical turnaround
Next 12 months
Semi-automated

Liquid handling and scheduling layers remove the repetitive steps, so the same team can carry more concurrent projects without losing oversight.

  • Automated liquid handling on core assays
  • Digital work instructions
  • Capacity up ~3×
2027 and beyond
High-throughput

A scheduling layer routes orders across qualified sites. Throughput becomes a function of the network, not of one building.

  • Multi-site capacity routing
  • Standardised data return
  • Order-to-result SLA
What "automation" means here: liquid handling and scheduling, not a lights-out lab. Scientists stay in the loop for design and exception handling; the repetitive transfer steps stop consuming their week.
03Capacity network

One order. Many benches.

Academic core facilities and specialist laboratories already own capacity that sits idle between grants. We qualify that capacity, standardise the data it returns, and route work to it — so a customer sees one contract and one report.

Discuss a volume programme

Each partner facility is audited on method fit, data format and turnaround before it receives work.

Routing

04
Return

Results come back in one format, under our quality system, with our name on the report.

What a partner facility has to pass before it receives work
Method fit

The facility can run the assay to our written method, not an approximation of it.

Data format

Results return in our schema — raw where it matters, summarised where it does not.

Quality system

Documented training, equipment qualification and deviation handling.

Turnaround

A committed window per batch, with escalation when it slips.

Why we are building it this way: a reagent supplier that also controls capacity can commit to a delivery date. One that does not, cannot — however good its catalogue is.
