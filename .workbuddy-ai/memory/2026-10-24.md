**调试经验**
- Chrome headless 在 Windows 有最小窗口宽度（约 497px），`--window-size=390` 无效 → 用 390px 宽 iframe 包裹页面来模拟移动端视口。
- `--virtual-time-budget` 下 CSS transition 不推进，抽屉类截图会停在 opacity:0 → 加 `--force-prefers-reduced-motion` 并在该媒体查询里禁用 `.mobile-menu` 过渡。
- 本地 http.server 遇到 Chrome 提前断开会抛 ConnectionAbortedError 并退出，长时间截图需重启服务。
